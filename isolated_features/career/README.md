# Isolated Feature: Career, Office Simulation, & Politics Module

Modul ini diasingkan dari game utama AuraAssets.
Modul ini mencakup seluruh engine pekerjaan kantor, mini-game simulasi kerja, asisten AI kantor, tangga karir korporat, dan sistem politik:

## Sub-Komponen:
1. **Office Dashboard & Workplace**: `js/WorkPage.js`
2. **Interactive Workplace Mini-Simulations**: `js/WorkSimulation.js` (typing, bug fixing, spreadsheet math, data approval)
3. **Task & Assistant Database**: `databases/WorkTaskManager.js`
4. **Career Progression Page & Modal**: `js/CareerPage.js` & `js/panels/CareerPanel.js`
5. **Political System & Elections**: `js/PoliticsManager.js` & `js/panels/PoliticsPanel.js`
6. **Role Modules**: `js/RoleModules.js`
7. **Stylesheets**: `css/career.css`, `css/work.css`

## HTML Shell Terkait:
- `#earn-panel` (Subsidi Pemerintah Daerah untuk Karyawan/Survivor)
- Quick Action cards: "Office" dan "Jenjang Karir"
